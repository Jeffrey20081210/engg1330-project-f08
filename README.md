# The Last Train from Central

HKU ENGG1330 (2026-27) Group Project, Subclass F, Group 8.

A turn-based ASCII puzzle adventure in the terminal: escape MTR Central
station before it seals at 01:30.

## Play

Install and start Docker Desktop, then in this folder run:

```
docker compose build
docker compose run --rm game
```

The terminal must be at least 80 x 24.
